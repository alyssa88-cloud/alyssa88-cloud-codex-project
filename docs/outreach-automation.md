# 自动开发与邮箱跟进

## 目标
符合客户画像且达到最低意向评分的客户，自动生成并发送英文开发邮件；无需人工逐封审核。

## 自动发送规则
- 市场：美国
- 客户：服装品牌、批发商、电商卖家
- 产品：内衣、内衣套装、塑身衣、睡裙
- MOQ：100 件
- 默认仅向有明确业务邮箱来源的公司联系人发送。
- AI 必须基于可验证证据生成个性化内容，不得虚构产品、采购行为、姓名或联系方式。
- 每封邮件记录发送时间、收件人、主题、正文版本、证据来源和发送结果。
- 发现退订/明确拒绝后，加入 suppression list，禁止继续自动触达。
- 对无法验证邮箱、明显不匹配、重复客户或风险较高的线索不发送。
- 建议设置每日发送上限、域名级限速和失败重试上限，避免误发和过量发送。

## 邮箱

系统的“我的邮箱”用途：
1. 发送开发邮件的发件邮箱。
2. 接收客户回复。
3. 接收跟进提醒。
4. 记录发送和回复状态。

部署到独立 Web 应用后，应通过 Microsoft Graph OAuth/应用授权完成邮箱连接，不把账号密码或访问令牌写入代码仓库。

## 跟进策略
- 首次邮件发送后，根据客户状态自动创建 follow-up task。
- 默认第 1 次跟进：5 个工作日后。
- 默认第 2 次跟进：再过 7 个工作日。
- 客户回复后停止自动跟进，并把线程标记为“已回复”。
- 退订、明确拒绝或无效邮箱后停止跟进。
- 每个待跟进任务向用户邮箱发送提醒邮件，包含公司、联系人、原邮件主题、建议动作和客户页面入口。
